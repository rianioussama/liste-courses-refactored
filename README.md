# SmartCourses refactored project

This project is a clean, modular shopping list app split into HTML, CSS and ES modules.

## Structure

- `index.html`
- `css/`
- `js/`
- `data/`
- `manifest.json`

## Features

- Catalogue with favorites and quantities
- Store mode with purchased tracking
- Weekly meal menu
- Budget overview
- Persistent local storage
- Responsive layout

## Run locally

Open `index.html` in a browser or serve the folder with a simple static server.

Example:

```bash
python -m http.server 8000
```

Then open: http://localhost:8000
